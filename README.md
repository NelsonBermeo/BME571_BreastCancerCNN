# Breast Cancer Detection - Ultrasound Image Classification Project

This project explores the use of deep learning for breast cancer detection using ultrasound images. The goal was to build and evaluate a convolutional neural network (CNN) and compare to ResNet18 model for classifying breast ultrasound scans as either alignant or non-malignant (benign + normal).

Dataset: "Dataset of breast ultrasound images" - https://www.sciencedirect.com/science/article/pii/S2352340919312181
